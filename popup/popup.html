After downloading, replace files in your local extension folder, then reload the extension in Chrome.

  1. Download Latest Version in popup and wait for ZIP download.
  2. Find ZIP in Downloads (usually ChromeExtension-main.zip).
  3. Extract all to folder (ChromeExtension-main).
  4. Use the same local folder as Load unpacked in chrome://extensions. If unsure: open chrome://extensions, then extension Details, then Extension root directory.
  5. Copy all extracted files into that target folder and replace destination files.
  6. Open chrome://extensions and click Reload for this extension.
  7. Verify popup reflects latest changes.
